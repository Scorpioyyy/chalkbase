## 2026-09-28 · Stage 1 不变量：课时挂载规则

- **"每个课时至少引入 1 个知识点"改为"`intro_knowledge_point_ids` 或 `practice_knowledge_point_ids` 至少一个非空"。** 原表述假设每课都在教新东西，但"整理与复习""练习 N"类课时是真实存在且合理的教材结构，只复现/练习已有知识点。用原表述会把这类正确课时误判为漏抽。仍然禁止一个知识点都不挂的空课时。
- **开学导入单元 `.u0` 豁免。** `g1a.u0`（"我上学啦"）的 5 个课时全是口头讨论、无编号练习，既不引入也不练习知识点，是合理的教材内容；数据模型的 `Unit.index` 本就为此类单元保留了 0 号。
- **豁免判据泛化为"是否被任何 `ExerciseInstance` 引用"。** `g5b.u11.l03`「学期总结」（纯反思模板）同样既无知识点也无习题，但不在 `u0` 下。判据改为：没有知识点也没有习题引用 = 非教学内容，放行；没有知识点但有习题引用 = 漏挂，报错。该判据无需逐个枚举特殊课时类型。
- 影响：不变量只会放宽到上述三类真实教材结构，不影响任何比例指标。

## 2026-09-29 · Stage 2 评测细化

- 新增 `eval/specs/stage2.md`，指标注册到 `chalkbase/eval.py`（`stage2_entity_resolution`）；`python -m chalkbase.eval` 增加 `--split {val,test}`；`reports/eval.md` 增加各阶段指标表（当前值 / CI / n / 基线 / 阈值 / 是否达标）与主要失败类别。
- **新增锚点标注数据。** 总体方案只规划了成对标注数据，但成对样本只能从候选对里抽（否则绝大多数是显然的 different），用它估计 blocking 召回是循环论证——标注正例天然都在候选集里。锚点标注数据让标注模型看到锚点知识点与其余全部 465 个知识点的清单，挑出全部 same / extends，正例不依赖 blocking，可无偏估计 blocking 召回；同时以"锚点 + 其 same 集合"为标注簇，在锚点上计算 B-cubed。
- **成对标注数据样本量调整。** 总体方案每层 ≥60 对共 200～300 对。`same` 正例在候选对中很稀少（30 对样本里只有 1 对），按原计划 `same` 类 P/R 的置信区间会过宽，因此把 H 层（sim ≥ 0.30）改为全量 317 对，另三层各 90 对，共 587 对。
- **锚点标注数据改为两步法。** 让标注模型直接在 465 个知识点清单（只有名称与主线）里挑 same/extends 时，两模型在并集上的一致率仅 0.32（κ≈0），且一致采纳里也有明显错误（如「制订并评价节水方案」与「生活用水调查与滴水实验的方法」被双方都判为 same）。改为：全表挑选只作宽松筛选（取并集），并集中每一对再按成对标注数据流程（完整描述 + 习题举例）逐对判定，逐对判定 κ = 0.77。
- **新增非平凡 B-cubed。** 锚点大多是单点簇，全体平均的 B-cubed 基线就有 0.97，区分度太低；增加只在标注簇或预测簇大小 ≥ 2 的锚点上计算的 B-cubed（val：系统 0.92；test：系统 0.89 / 基线 0.81）。
- **新增"聚类后 same"的成对指标。** 判定级 P/R/F1 看不到传递性误并，而这是早期聚类的主要问题（判定级 `same` 精确率 0.88，聚类后 0.79，见 D13）。

## 2026-10-03 · 题型实例化：模板占位符与无解参数（新增不变量 V7 / V8）

- **发现。** 题型实例化运行时（`chalkbase.runtime`）对全部 1313 张 program 题型 × 5 个种子做 smoke，发现 163 张卡片的模板含没有对应槽位的占位符（如 `{a1}`、`{sum}`、`{ans1_bool}`；多为求解程序内部的中间量或本应是待作答空位的答案），渲染出的题面带着未替换的花括号；另有 3 张卡片的求解程序对多数随机参数返回 None（无解）。此前的程序校验只重算卡片自带的 2～3 个示例与探针里"可运行、满足约束"，没有检查模板能否被槽位完整渲染。
- **新增校验。** V7：模板占位符必须是槽位名、由槽位组成的算术表达式（`{a + b}`、`{a // b}`、`{a ** 2}`，AST 白名单、精确数值）或空位（`blank` / `ans` / `answer` / `result` / `quotient` / `remainder` 开头）。V8：求解程序对满足约束的随机参数返回 None 的比例不得超过 1/4。V7 对三类可验证类型都适用；rule / human 另加"槽位约束能采到参数"（此前只对 program 做生成探针）。新增不变量 `test_every_program_template_placeholder_resolves`，rule / human 的例外名单 `KNOWN_UNRENDERABLE_NON_PROGRAM` 只许缩短。
