# Stage 5 评测规格：版本对齐、补全与约简

函数：`stage5(KP 表, 课时表, 边表, 课标清单) → (自洽的 KP 表, 课时表, 边表)`。入口 `python -m curriculum.stage5`，必须幂等（对自己的输出再跑一次不产生变化）。

范围说明（用户指示「抓大放小」）：本阶段只对 `prerequisite` 边施加自洽约束；`builds_on / related / confusable / extends` 不参与修复。题型卡片不在本阶段生成（缺口知识点的卡片待办清单见 `data/gap_kps_pending_cards.json`）。

## 1. 失败模式与检测

| # | 失败模式 | 检测手段 | 类型 |
|---|---|---|---|
| F1 | 把判定错误当版本冲突，硬前移了不该前移的知识点 | 对每条逆序前置边先分诊（版本冲突 / 判定错误 / 同书内课时顺序偶然）；`reconciled` 条目由两模型审阅（D13 组合），通过率报 Wilson CI | 组件指标 |
| F2 | 前移过多（不是恰好满足约束） | 不变量：每个被前移的知识点，新引入课时恰等于某条出边终点 B 的引入课时（最小性） | 不变量 |
| F3 | 前移/补全后仍有前置边违反 A 不晚于 B | 不变量：全部 `prerequisite` 边 A→B 满足 pos(A) ≤ pos(B)，100% | 不变量 |
| F4 | 前移引入环 / 原图有环 | 不变量：`prerequisite` 子图为 DAG | 不变量 |
| F5 | 缺口遗漏（被假定已学但无引入） | (a) 模型逐知识点枚举「被假定已学、清单中没有」的概念；(b) 课标条目覆盖映射；(c) 种子探针：D14 的「长方形/正方形的面积」「面积单位」必须被找到 | 组件指标 + 探针 |
| F6 | 缺口误报（其实已被某知识点覆盖，造出重复知识点） | 缺口候选先过「是否已被现有知识点覆盖」二分类判定；`reconciled` 审阅同时检查 | 组件指标 |
| F7 | 缺口知识点定位错（年级/前置不合理） | 前置边由模型从全表挑选并以 Judgment 落盘；审阅检查引入位置合理性；不变量 F3 保证自洽 | 审阅 |
| F8 | 传递约简改变了可达性 / 误删非冗余边 | 不变量：约简前后闭包相同；`is_direct=False` 的边必有一条替代路径 | 不变量 |
| F9 | 引用悬空：边、课时、复现位置引用不存在的知识点 | 不变量（引用可解析、课时 intro 与 `first_introduced_lesson_id` 一致、intro/practice 不重叠） | 不变量 |
| F10 | 派生量过期：题型难度仍用旧引入位置 | 不变量：题型的 `difficulty_features.intro_span_semesters` 等于按当前引入位置重算的值（`archetypes.json` 尚未重算时测试给出明确失败信息；由重算命令修复） | 不变量 |
| F11 | 修复损害 Stage 4 关系质量（闭包 P/R/F1 下降） | 沿用 Stage 4 金标在最终图（含约简后）上重算，与修复前对比 | 组件指标 |
| F12 | 课标覆盖不完整 / 覆盖映射不可靠 | 每条课标条目对「是否被某知识点覆盖」二分类（两个不同厂商模型 + 分歧仲裁，Judgment 落盘）；不变量：映射完备（每条要么有覆盖知识点，要么有逐条写明的不适用理由）；清单本身是否核实过原文如实标注 | 不变量 + 指标 |
| F13 | 误把课标「不适用」当作全覆盖的借口 | 不适用条目数单独报告，逐条列理由，停顿点抽查 | 人工抽查 |

暂不检测：补全知识点的 `grants` 是否精确（Stage 6 的越界探针会间接暴露）；`builds_on` 边的顺序冲突（不参与自洽条件，D16 已将其定义为「递进但不确定必需」）。

## 2. 评测数据

- 逆序前置边：全量（修复前 11 条）。
- `reconciled` 条目（前移 + 补全 + 删改边）：全量审阅（预计 < 100 条，overview 约定 > 150 条才分层抽样）。
- 课标条目：全量二分类。

## 3. 阈值与动作

| 指标 | 阈值 | 不达标动作 |
|---|---|---|
| 自洽（F3）、无环（F4）、约简保持可达（F8）、引用可解析（F9）、映射完备（F12） | 100% | 硬门槛，不进入 Stage 6 |
| `reconciled` 审阅通过率（两模型一致通过 + 仲裁通过） | ≥ 0.90 | 重新处理未通过项（改位置 / 删除条目） |
| 课标覆盖率（覆盖 + 逐条说明不适用） | 100% | 为未覆盖条目补全知识点，回到修复步骤至不动点 |
| 最终图闭包 F1 相对修复前 | 下降 ≤ 0.02 | 复核被删改的边与新增的缺口边 |
| D14 种子缺口被找到 | 2/2 | 检查缺口发现提示词 |
