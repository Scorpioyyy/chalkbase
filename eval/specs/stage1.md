# Stage 1 评测规格：抽取观测

细化自 `eval/specs/overview.md`，按 CLAUDE.md 4.1 节流程。

**输入**：12 册 PDF。**输出**：`work/books/<book_id>/`（课程结构、局部知识点、习题实例、情境与术语观测）。

## 1. 失败模式清单

1. **漏抽**：页面上有习题但未生成 `ExerciseInstance`。
2. **误抽**：生成了教材上不存在的习题（幻觉）。
3. **知识点粒度错误**：把一个考点拆成多个，或把两个不同考点合并成一个；把课时标题（情境名）误当知识点。
4. **关键字段错误**：`item_form` / `answer_form` / `operand_features` / `primary_knowledge_point_id` 标错。
5. **课时归属错误**：习题被记到错误的课时；Lesson 边界划分错误（把两课内容合成一课，或把一课拆成两课）。
6. **`text` 摘录失真**：原文摘录或图形描述丢失关键信息（如漏掉图中的数值、方向、数轴刻度）。
7. **`grants` 草稿不合理**：能力增量维度选错或数值错误（如整数数域上限抄错）。
8. **显式引用漏记**：教材"回顾以前所学"类的原文引用没有被记录到 `explicit_review_refs`。
9. **情境/术语观测遗漏或归并过粗**：不同情境被合并记录，或明显重复的情境被记成多个。

## 2. 检测手段

| 失败模式 | 检测手段 |
|---|---|
| 1 漏抽 | 不变量：页面练习标记与实例数的启发式比对（见 §3） |
| 2 误抽 | 双盲一致性 + 对照原页面核对 |
| 3 粒度错误 | 双盲一致性（知识点集合 Jaccard）+ 对照核对 |
| 4 字段错误 | 双盲一致性（字段级一致率）+ 对照核对 |
| 5 归属/边界错误 | 不变量：每课时至少挂载 1 个知识点；对照核对 |
| 6 `text` 失真 | 对照原页面核对（唯一能对照原页面的环节） |
| 7 `grants` 草稿不合理 | Stage 6 以"实例是否超出所在课时边界"反向暴露并修正（D21） |
| 8 显式引用漏记 | 下游 Stage 4 候选召回率间接反映 |
| 9 情境/术语归并问题 | Stage 3 汇总时抽查；本阶段如实记录原始观测，暂不单独检测 |

## 3. 不变量（`tests/test_stage1_invariants.py`）

- Schema 合法：`Lesson` / `KnowledgePoint` / `ExerciseInstance` 均可被 pydantic 解析。
- 每个 `Lesson` 的 `intro_knowledge_point_ids` 或 `practice_knowledge_point_ids` 至少一个非空。"整理与复习""练习 N"类课时只复现/练习已有知识点，因此该条是二选一非空，而不是"每课时至少引入 1 个知识点"。例外：没有任何知识点、也没有任何习题引用的课时（开学导入单元 `.u0`、学期总结的纯反思页）不是教学内容，放行；有习题引用却没有知识点挂载的课时一律报错（见 `eval/CHANGELOG.md`）。
- 每条 `ExerciseInstance.lesson_id` / `primary_knowledge_point_id` 都能在同一本书的 `lessons.json` / `knowledge_points.json` 中解析到。
- 每个 `Unit` 的 `lesson_ids` 与实际挂在该单元下的 Lesson 一致；`Lesson.pages` 落在所属 `Unit.pages` 范围内且互不重叠。
- 页面覆盖启发式：统计每本书"含练习标记"的 PDF 页被至少 1 条 `ExerciseInstance.pdf_page` 引用的比例，记录在各书 `progress.md`，作为软指标，不设自动失败阈值（重点看有无整页漏抽）。

## 4. 评测数据与抽样

- **双盲一致性**（用于抽取指南定稿，在 `g4a`、`g4b` 上执行）：每本书抽 2 个单元，由两个互不知情的抽取者独立抽取。指标：知识点集合 Jaccard；`ExerciseInstance` 按 `(pdf_page, 题目在页面内的序号)` 对齐后计算 `item_form`/`answer_form`/`primary_knowledge_point_id`/`requires_figure` 的字段级一致率。
- **对照核对**：从 `g4a`、`g4b` 产出中抽 5 页（有文字层与无文字层各至少 2 页，覆盖不同 `item_form`），对照原书页面核对实例的查全、查准与关键字段准确率。
- 其余 10 册为单遍抽取，由不变量与下游阶段（Stage 2–6）的一致性检查把关。

## 5. 阈值与动作

| 指标 | 阈值 | 不达标动作 |
|---|---|---|
| 双盲知识点集合 Jaccard | ≥ 0.80 | 修订《抽取指南》的粒度判断部分，重做双盲 |
| 双盲实例字段级一致率 | ≥ 0.85 | 修订指南对应字段的判定规则 |
| 对照核对：实例查全率 / 查准率 | ≥ 0.95 | 修订指南，扩大后续抽取的抽查比例 |
| 对照核对：关键字段准确率 | ≥ 0.90 | 同上 |

不达标时先做错误分析（按失败模式分类计数），优先修订占比最大的失败模式对应的指南部分。

## 6. 基线

无更简单的对照方法（抽取本身即观测）；以双盲一致性的初次结果作为"指南修订后是否有提升"的基线。

## 7. 最终结果

自动化评测（`python -m chalkbase.eval`，直接由 `data/` 与 `work/books/` 计算）：

| 指标 | 结果 |
|---|---|
| 已抽取教材册数 | 12/12（阈值 12/12，达标） |
| 课时 / 习题实例数 | 567 / 4319 |
| 含「未能判读」图形信息的实例占比 | 0.0025 [0.0014, 0.0046]（11/4319） |

全部 Stage 1 不变量通过。双盲一致性与对照核对属于指南定稿阶段的检查，其结论体现为抽取规则的修订（D7–D9），不属于自动化评测，数值未纳入 `reports/eval.md`。

**误差与局限**：(1) 全书未做逐页对照，抽取质量由不变量与下游一致性（如 Stage 6 的"实例不越界"检查暴露了 1 例把 18 位身份证号当整数的抽取错误，D21）间接保证；(2) 图形信息因渲染精度未能判读的实例约 0.25%，按 D9 不做二次渲染核实；(3) 少数课时的知识点挂载偏向相邻课时（"开篇探索"类习题，23 条），按 D29 容忍。
