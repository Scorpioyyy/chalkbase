# 总体评测方案

三层评测（不变量 / 组件指标 / 下游探针）的定义见 CLAUDE.md 4.2 节；每个 Stage 的评测规格见本目录下的 `stage1.md`～`stage7.md`，最新结果见 `reports/eval.md`。

样本量估算：对比例型指标（P/R/F1、通过率），目标 Wilson 95% CI 半宽 ≤ 0.05 时，真值在 0.5 附近约需 n≈380，在 0.9 附近约需 n≈140。标注数据由模型标注、构造成本低，样本量按较窄的置信区间确定；抽样复核只用于估计标注数据本身的准确率。

## 各阶段评测一览

## 标注模型组

- 首轮独立标注：`qwen3.8-flash` + `deepseek-v4.1-flash`（不同厂商，非思考模式，互不可见）。
- 仲裁：`qwen3.8-max`（思考模式），仲裁置信度 < 0.7 进入低置信度队列。
- 流水线判定（非标注数据）：`qwen3.7-plus`，不进入任何标注模型组。
- 依据：30 对实体消解样本上，`qwen3.8-flash`、`deepseek-v4.1-flash` 非思考模式与独立参照标注的一致度为 30/30、29/30，开思考模式没有提升而费用高 40～60%（D13）。

## 通用约定

- 每个 Stage 的评测规格含：失败模式、检测手段、评测数据、阈值与动作、基线、最终结果与误差分析。
- val 用于开发调参，test 只在阶段验收时运行；某次 test 验收未过线并已看过其错误样本后，该 test 并入开发集，另抽新验收集（Stage 4 锚点、Stage 7 检索探针），指标定义不变。
- 所有比例指标报告 Wilson 95% CI；逐条取值的均值（recall、MRR）用 bootstrap CI。
- 评测定义的调整记录在 `eval/CHANGELOG.md`，指标变更后重算历史版本。
- 标注数据质量（κ、一致/仲裁/低置信度队列条数、费用、抽样复核准确率）见 `reports/eval.md`「标注数据质量」；已知局限见 `eval/known_limitations.md`。
