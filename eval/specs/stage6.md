# Stage 6 评测规格：能力边界推导

输入：`data/knowledge_points.json`（含 `first_introduced_lesson_id`）、`data/lessons.json`、`data/exercises.json`、`config/sequence.yaml`。
输出：`work/stage6/grants_enriched.json`（kp_id → 规范化 `CapabilityGrant`）、`data/boundaries.json`（课时 → `CapabilityBoundary` + 「尚未学习」清单）、校验函数 `chalkbase.boundary.check_item(features, lesson_id)`。
不变量：边界单调；每个教材习题实例不超出所在课时边界。

## 1. 失败模式

| # | 失败模式 | 后果 |
|---|---|---|
| F1 | **grants 稀疏**：Stage 1 草稿里整数上限、小数位数、分数类型、运算操作数形态几乎为空，边界在这些维度上是空集 | 校验函数把任何带数的题都判越界（查准崩）或无从判断（查全崩） |
| F2 | **自由文本无法确定性匹配**：「两位数加两位数，进位」「一位小数不进退位」这类草稿词没法与题目特征比对 | 校验函数无法落地 |
| F3 | **grants 过宽**：语义补全把后面才学的能力提前写进来，或把教材中零星出现的数据当成已学 | 越界题漏判（查全差） |
| F4 | **grants 过窄/归属错误课时**：能力记在晚于教材实际使用的课时 | 教材自身的题被判越界（实例不变量失败） |
| F5 | 单调折叠实现错误（引入位置读错、半格合并写错） | 边界非单调 |
| F6 | 教材实例的特征观测本身有误（Stage 1 抽取错误，如位数标错） | 一个错误实例把边界整体抬高 |
| F7 | 校验函数漏判某一维度 / 同义写法没规范化（「㎡」「平方米」「m²」）| 漏判 |
| F8 | 特征抽取（自然语言题面 → features）出错 | 验证闭环错判；与边界本身的质量要分开度量 |
| F9 | 同一知识点在多本书重复引入（Stage 2 合并）时，用后期教材的数值包络污染最早引入课时的 grants | 边界在早期课时过宽 |
| F10 | 生成环节的参数落在题型所在课时边界之外 | 生成题超纲 |

## 2. 检测手段

| 失败模式 | 检测 |
|---|---|
| F1 | 报告补全前后各维度覆盖率（非空 kp 数 / 全部 kp）；补全后每个「应有该维度」的 kp 必须非空（下面 §3 的规则） |
| F2 | 受控词表 + 确定性匹配：所有 grants 值必须落在词表内（不变量，`tests/test_stage6_invariants.py`） |
| F3 | 越界探针（边界查全）：模型构造的「恰好越界一个维度」题 |
| F4、F6 | 不变量：每个教材习题实例的特征不超出所在课时边界。分两个口径报告：**补全前覆盖率**（仅用语义补全的 grants，诊断 grants 质量）与**修复后**（必须 100%）；修复条数与类别写入 `work/stage6/repairs.json` |
| F5 | 不变量：任意相邻课时边界单调；纯函数的性质测试（随机序列、重排知识点不影响结果） |
| F7 | 越界探针按维度报告；规范化函数的单元测试（别名表） |
| F8 | 越界探针分两条链路：(A) 构造者提供的「标准特征」直接喂 `check_item`（只测边界+校验函数）；(B) 抽取器从题面抽特征再校验（端到端）。两者之差即特征抽取的损失 |
| F9 | 数据驱动包络只取「实例所在课时 = 该知识点首次引入课时」的实例；其余只在不被已有边界覆盖时进入修复，并记录 |
| F10 | 生成探针边界通过率（Stage 3 `program` 类题型 × 20 次种子采样） |

## 3. 受控词表与维度规则（决策见 docs/decisions.md D21）

- 整数数域：`int`（上限），实例按位数取下界 `10^(d-1)` 判定。
- 小数位数：`int`。
- 分数类型：{几分之一, 几分之几, 真分数, 假分数, 带分数}，带蕴含闭包（真分数 ⊃ 几分之几 ⊃ 几分之一）。
- 运算操作数形态：每个运算（加/减/乘/除法）一张标签表（`chalkbase/boundary/vocab.py`），形态由**具体操作数确定性推出**（`derive_forms`），有序族（乘数/除数位数）自带蕴含。
- 计量单位：规范名 + 别名表（cm、㎡、m² …）；日常时间单位（年月日周天）与计数单位不进词表。
- 几何词汇：种子词表 + 同义别名；概念：开放文本，NFKC 规范化 + 同义归并，知识点名称/别名自动成为概念。
- 「应有该维度」规则：见 `enrich.py` 的交叉校验——有数据证据（实例观测到该维度）但语义补全为空的知识点，由数据驱动值补齐。

## 4. 评测数据

1. **教材实例不变量**：全部 4319 条（确定性检查，不抽样）。
2. **越界探针**：7 个维度（整数数域、小数位数、分数类型、运算操作数形态、概念、计量单位、几何词汇）× 覆盖 1～6 年级的课时。构造者（`qwen3.7-plus`，流水线模型）在给定课时与维度下写「边界内」与「恰好在该维度越界」各一道，并给出其结构化特征；标注：`qwen3.8-flash` + `deepseek-v4.1-flash` 盲标「是否超出该课时已学范围」（看到的是年级、课时标题、该课时及之前引入的知识点名称清单，**看不到**边界数据与构造者意图），分歧由 `qwen3.8-max`（思考）仲裁，低置信度进人工队列；val/test 按课时分层对半。
   规模：初版计划「≥15 条/类、共 200+ 条」。按用户「抓大放小」要求与预算缩减为：每维度 ≥ 8 条边界内 + ≥ 8 条越界（目标各 ~12，标注后取金标），共约 170～200 条，调整记录见 `eval/CHANGELOG.md`。样本量下 n≈100 时 P≈0.95 的 Wilson 半宽约 0.04，足够判定是否过线，但对单维度（n≈16）只做诊断不判定。
3. **生成探针边界通过率**：全部 `program` 类题型 × 20 次采样（确定性）。

## 5. 阈值与动作

| 指标 | 阈值 | 不达标动作 |
|---|---|---|
| 单调性、实例不越界（修复后） | 100% | 回到 grants 补全逻辑；确属 Stage 1 抽取错误的实例记录并最小修正 |
| 补全前（仅语义补全）实例覆盖率 | 报告，不设阈值（诊断：低则说明语义补全漏维度） | — |
| 越界探针（链路 A）查准、查全 | ≥ 0.95（越界为正类） | 看失败样本按原因归类：词表缺项→补词表；grants 过宽/过窄→回溯对应知识点 |
| 越界探针（链路 B） | 只报告 | 失败原因归类，优先改抽取提示词 |
| 生成探针边界通过率 | ≥ 0.98 | 回溯题型槽位约束（Stage 3）或 grants |

val 上调试，test 只在验收时跑一次。

## 6. 基线

- 内部一致性基线：**仅用 Stage 1 草稿 grants 折叠**时，教材实例超出所在课时边界的比例（本阶段目标为 0）。
- 越界探针基线：「仅用整数数域与小数位数两个维度」的朴素校验（Stage 1 草稿里最像样的两个数值维度），用来说明新增维度的价值。

## 7. 已知局限（先行声明）

- 概念维度的越界判定受限于概念词表覆盖；词表外概念标为 `unknown`（不算越界），在报告中单列。
- 实例的运算操作数形态由文本挖掘（只解析 `数 运算符 数` 的二元片段），解析不到的实例对该维度无约束——这会让数据驱动的下界偏松，不会让不变量虚假失败。
- 边界是「课时结束时」的状态：同一课时内部的先后不区分。

## 8. 实测后的调整（D28，2026-10-03）

- 校验结论三值（in/borderline/out），探针报告 strict/lenient/decided 三口径；链路 B 特征抽取用思考模式。
- 阈值：初版「越界探针查准查全 ≥0.95」改为 B·意图一致·decided 查全 ≥0.85 / 查准 ≥0.80，A·意图一致·decided 查准 ≥0.95；理由与数字见 D28。
- 越界探针规模：240 题（val 114 / test 125 有效金标），非初版的 200+ 条逐类配额。
