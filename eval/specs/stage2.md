# Stage 2 评测规格：知识点实体消解

细化自 `eval/specs/overview.md`，按 CLAUDE.md 4.1 节流程。

**输入**：`work/books/*/knowledge_points.json` 中全部 466 个局部知识点（12 本书；局部 ID 跨书有 21 个重名，全局以 `书::局部ID` 为键）。
**输出**：`data/knowledge_points.json`（规范知识点目录）、`data/kp_local_map.json`（局部→规范映射，覆盖全部 466 个局部知识点）、`data/lessons.json` / `data/books.json`（课程结构，知识点引用改写为规范 ID）、`data/edges_extends.json`（`Edge(type=extends)`）、`work/judgments/stage2_pairwise.jsonl`（每次成对判定的 `Judgment`）。

## 1. 失败模式清单

1. **Blocking 漏召回**：真正应合并（或构成螺旋扩展）的一对知识点没有进入候选，判定环节永远看不到它。典型风险：跨主线命名不一致（如「观察物体」vs「观察物体（三视图）」、「确定位置」vs「方向与位置」）、跨领域归类不一致、名称措辞差异大。
2. **漏并（假 different）**：同一考点在不同书（尤其新旧版之间，如 g4b 与 g5a 的「小数加减法」）未合并，规范目录出现重复。
3. **误并（假 same）**：不同考点被合并，信息被抹掉。其中两类单独关注：
   - 3a. **扩展被误判为同一**（最危险）：螺旋上升的内容（「万以内数比较大小」vs「亿以内数的大小比较」）被合并，会让能力边界与前置关系全部错位；
   - 3b. **伞形复习点吞并具体点**：g6b 总复习类伞形知识点与具体知识点合并，把一群具体知识点通过传递性连成一个大簇。
4. **传递性误并**：两两判定都「看起来」合理，但连通分量把 A–B–C 链成一个过大的簇。
5. **扩展方向错误**：`extends` 的方向（窄→宽）颠倒，污染 Stage 4 证据。
6. **约束违反**：同一课时内被抽取者刻意区分的两个知识点被合并。
7. **映射不完整 / 引用悬空**：某个局部知识点没有映射；映射到不存在的规范 ID；规范 ID 不唯一或不符合 ID 约定。
8. **规范知识点属性合并错误**：首次引入课时不是成员中最早的；复现课时丢失；别名丢失。

## 2. 检测手段

| 失败模式 | 检测手段 |
|---|---|
| 1 Blocking 漏召回 | **锚点标注数据**（§3.2）上的 blocking 召回率：标注数据 same（及 extends）对中进入候选的比例 |
| 2 漏并 | 成对判定 `same` 类召回率（成对标注数据）；锚点 B-cubed recall |
| 3 误并 | 成对判定 `same` 类精确率；锚点 B-cubed precision |
| 3a 扩展→同一 | 单独指标：成对标注数据中 gold=`extends` 的对被预测为 `same` 的比例 |
| 3b 伞形吞并 | 不变量：规范簇大小分布，簇 > 4 个局部成员的逐个列入错误分析；含「总复习」知识点的对单独统计误并数 |
| 4 传递性误并 | 锚点 B-cubed precision（直接衡量簇级误并）；最大簇大小监控；"聚类后 same"的 P/R/F1（判定级指标看不到传递性误并） |
| 5 方向错误 | 成对标注数据中双方都判 `extends` 的对，方向一致率 |
| 6 约束违反 | 不变量（pytest）：同一课时的 `intro_knowledge_point_ids` 中两个不同局部知识点不得映射到同一规范 ID |
| 7 映射问题 | 不变量（pytest）：466 个局部知识点全部有映射；映射目标存在；规范 ID 唯一且符合 `kp.<领域>.<主线>.<slug>`；`data/lessons.json` 引用全部可解析 |
| 8 属性合并 | 不变量（pytest）：规范知识点 `first_introduced_lesson_id` = 成员中教学序列最早的引入课时（`reconciled` 知识点为"不晚于"）；成员的引入/复现课时全部出现在规范点的引入或复现课时中；成员名称全部出现在 name/aliases 中 |

## 3. 评测数据

两类标注数据，均按 CLAUDE.md 4.3 节流程生产（指南 `eval/annotation/entity_resolution/guideline.md`）。

### 3.1 成对标注数据（衡量成对判定质量）

- **总体**：Blocking 产出的全部候选对（判定环节只会看到候选对）。
- **分层抽样**（按 TF-IDF 余弦相似度与来源分层，覆盖困难样本）：H：sim ≥ 0.30（317 对全量，最可能 same，也是"扩展误判为同一"的主要来源）；M：0.15 ≤ sim < 0.30（90 对）；L：sim < 0.15 且来自 TF-IDF 路（90 对）；T：仅来自"同主线相邻学期"路（90 对）。共 587 对。依据：`same` 正例在候选对中很稀少（30 对样本里只有 1 对），H 层取全量才能让 `same` 类 P/R 的置信区间足够窄（n≈140 时 Wilson 半宽 ≈0.05）。
- **划分**：每层内随机 50/50 划分 val / test（固定随机种子）。

### 3.2 锚点标注数据（衡量 blocking 召回与簇级质量，不受候选集限制）

- 抽样 129 个局部知识点作为锚点（按领域 × 年级段分层：低 1–2、中 3–4、高 5–6 年级，按各层知识点数比例分配，每层至少 4 个）。
- **两步法标注**：(1) **全表筛选**——两个标注模型各自看到锚点的完整信息与全部其余 465 个局部知识点的清单（书、名称、领域、主线），挑出可能 `same` / `extends` 的知识点，取并集作为宽松候选；(2) **逐对判定**——并集中每一对按成对标注数据的完整流程（完整描述 + 习题举例，盲标 + 仲裁）标注。筛选不依赖 blocking，可无偏地估计 blocking 召回。直接让模型在 465 项清单里挑选 same/extends 时，两模型在并集上的一致率仅 0.32（κ≈0），且一致采纳里也有明显错误，因此清单只用作宽松筛选；逐对判定的 κ = 0.77。
- 标注簇：锚点 + 其全部 `same` 知识点（B-cubed 在锚点条目上平均）。
- **划分**：65 val / 64 test（分层随机）。

### 3.3 标注模型组（独立性原则，CLAUDE.md 4.3.7）

- 流水线成对判定模型：`qwen3.7-plus`（不进入任何标注模型组）。
- 首轮盲标：`qwen3.8-flash` + `deepseek-v4.1-flash`（不同厂商，非思考）。
- 仲裁：`qwen3.8-max` 思考模式；仲裁置信度 < 0.7 进入低置信度队列。
- 指南校准：从成对样本中取 30 对，候选配置全部跑一遍并与独立参照标注比较，据分歧修订指南（D13）。

### 3.4 抽样复核

从"一致采纳""仲裁采纳"两层各抽样（成对 12 + 12，锚点 5 + 5），估计标注准确率（Wilson CI）写入 `reports/eval.md`：成对 24/24（下限 0.862），锚点 10/10（下限 0.723）。

## 4. 指标、阈值与动作

| 指标 | 定义 | 阈值 | 不达标动作 |
|---|---|---|---|
| Blocking 召回率 | 锚点标注数据 same 对中进入候选的比例 | ≥ 0.95 | 引入向量召回作第二路，或增大 k |
| Blocking 召回率（extends） | 锚点标注数据 extends 对进入候选的比例 | 报告，不设阈值（Stage 4 另有自己的候选生成） | — |
| 成对 `same` F1 | 成对标注数据上 `same` 类 P/R/F1 | F1 ≥ 0.85 | 错误分析 → 修订判定提示词 / 换思考模式 |
| 扩展→同一误判率 | gold=`extends` 中预测为 `same` 的比例 | ≤ 0.05（单独过线） | 修订提示词中扩展判据；必要时对"同主线不同数域"加规则 |
| 三分类 macro-F1 | same/extends/different | 报告 | — |
| 簇级 B-cubed F1 | 锚点上平均；另报告仅在标注簇或预测簇大小 ≥ 2 的"非平凡"锚点上的 B-cubed（多数锚点是单点簇，全体平均被稀释，基线也能拿到 0.97） | ≥ 0.85 | precision 低 → 查传递性误并与约束；recall 低 → 查 blocking / 漏判 |
| 扩展方向一致率 | 双方都为 extends 的对中方向一致 | 报告 | — |

所有比例指标附 Wilson 95% CI。开发调参只看 val，test 只在阶段验收时跑。

## 5. 基线

**名称完全匹配合并**：两个局部知识点 `name` 字符串完全相同即判 `same`，否则 `different`；以 `same` 为边求连通分量。基线没有 blocking，其候选即名称相同的对，blocking 召回一栏对基线报告"名称相同对"占标注数据 same 对的比例。

## 6. 错误分析类别

`扩展误判为同一`、`漏并（措辞差异）`、`漏并（跨主线/领域）`、`伞形复习点误并`、`不同考点误并`、`方向错误`、`其他`。由规则先粗分（是否含"总复习"、主线是否相同、gold/pred 组合），再复核。

## 7. 最终结果与误差分析

test 划分（标注数据仅在阶段验收时使用）：

| 指标 | 阈值 | 结果 | 基线 |
|---|---|---|---|
| blocking 召回率（same） | ≥ 0.95 | 1.0 [0.785, 1.0]（n=14） | 0.357 |
| 成对 `same` F1 | ≥ 0.85 | 0.96（P 0.923 [0.759, 0.979]，R 1.0 [0.862, 1.0]） | 0.80 |
| 扩展→同一误判率 | ≤ 0.05 | 0.031 [0.009, 0.107]（n=64） | 0.0 |
| 三分类 macro-F1 | 报告 | 0.915 | 0.825 |
| 簇级 B-cubed F1 | ≥ 0.85 | 0.978（P 0.982，R 0.974） | 0.972 |
| 非平凡锚点 B-cubed F1 | 报告 | 0.891（n=13；P 0.910，R 0.872） | 0.811 |

全部阈值达标；全部不变量通过。

**误差分析**：test 上的判定级失败为 `扩展漏判为不同` 14 例（占大头）、`不同误判为扩展` 4 例、`扩展误判为同一` 2 例。螺旋上升的内容（如口算 → 笔算、范围扩大）有时被判为不同知识点，因此规范知识点偏多而非偏少；偏多对下游无害（只是少了一条 `extends` 边），偏少会把应分开的合并，后者（`extends_as_same_rate`）只有 0.03。聚类约束的设计与效果见 D13（判定冲突约束使开发集聚类后 `same` 精确率 0.79 → 0.91）。锚点上的多数条目是单点簇，因此另报非平凡锚点的 B-cubed。
