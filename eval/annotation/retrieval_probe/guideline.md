# 标注指南：检索探针标准答案（教师需求 → 应命中的知识点）

## 背景

老师会用口语化的方式提出出题需求（如「四年级小数加减法的拔高题」）。系统需要从课程知识库中检索出这条需求所对应的**知识点**。你的任务是：给定一条老师的需求和知识库中全部规范知识点的清单，挑出「一个好的检索系统应当返回」的知识点。

知识库来自北师大版小学数学 12 本教材（g1a 一年级上册 … g6b 六年级下册）。注意：
- 本套新版教材把部分传统内容**后移**了：面积在五年级上册（g5a）才系统学习；分数运算、折线统计图主要在五、六年级；三年级没有「面积」。老师的需求可能按传统教材的年级说法提出。
- g4b/g5b/g6b 是旧版教材，其余是新版，同一内容可能在两个年级都出现。清单中每个知识点列出了「引入」书与「复现」书。

## 两个档次

- `core`（核心）：需求**直接点名要考**的知识点。检索系统必须把它们排在最前面。例如「四年级小数加减法的拔高题」→ 小数加减法相关的知识点（含进位退位、位数不同等）。
- `related`（相关）：需求中**明确提到要混入/复习/结合**的其他知识点，或需求所说的内容必然要用到且老师会期待一起出现的知识点。例如「出小数乘法，把三年级学的乘法竖式带进来复习」→ 小数乘法为 core，整数乘法竖式为 related。

不要为了「保险」把同一领域的大量知识点都放进来：`core` 通常 1～6 个，`related` 通常 0～6 个。一个知识点只能出现在一个档次里。

## 判定要点

1. **按内容匹配，年级只用来消歧**。同一内容在多个知识点里时（如整数加减法按数域分成多个），优先选与需求年级相符的那个；需求年级与教材实际编排不符时（如「三年级面积」），仍然选内容对应的知识点（即使它在五年级），并把 `grade_mismatch` 设为 true。
2. **跨单元/综合类需求**（如「期末把这学期的数的认识和加减法揉在一张卷子里」）：core 选该范围内的主干知识点，控制在 6～10 个以内，选最有代表性的，不要穷举。
3. **总复习类知识点**（名称带「总复习」）：只有需求本身就是总复习/综合卷时才选。
4. 找不到任何对应知识点时 core 给空列表，并在 reason 里说明。

## 输出格式

只输出 JSON：

```json
{"core": ["编号", ...], "related": ["编号", ...], "grade_mismatch": true|false, "confidence": 0.0~1.0, "reason": "不超过80字"}
```
