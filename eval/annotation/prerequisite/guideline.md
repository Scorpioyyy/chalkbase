# 标注指南：知识点之间的依赖关系（prerequisite / builds_on / related / confusable / none）

## 背景

知识库来自北师大版小学数学 12 本教材（g1a 一年级上册 … g6b 六年级下册），已经把同一知识点在不同书里的重复合并成一个规范知识点。现在要判断两个知识点 A、B 之间的关系，核心问题是：

> **不掌握 A，学生能否学会 B？**

注意：
- 这是关于**知识本身的依赖**，不是关于教材的编排顺序。教材版本混杂（g4b/g5b/g6b 为旧版 2011 课标，其余为新版 2022 课标），新版把一些传统内容后移（面积到五年级、分数运算和折线统计图到五六年级）。**不要用「传统上应该先学哪个」的常识，也不要因为教材里 A 比 B 晚出现就否认 A 是 B 的前置**——如果知识上确实需要，就判前置，即使它和教材顺序相反（这种冲突会在后续环节统一修复）。
- 依赖可以是间接的：如果不掌握 A 就学不会某个 C，而不掌握 C 就学不会 B，那么不掌握 A 也学不会 B，同样判 `prerequisite`。

## 五个标签（关系有方向时，方向一律按 A → B 理解）

### `prerequisite`：A 是 B 的前置
不掌握 A，就**无法**学会 B：B 的定义、算法或解题过程直接建立在 A 上。
- 「乘法的意义」 → 「表内乘法口诀」
- 「两位数乘一位数」 → 「两位数乘两位数的竖式计算」
- 「长方形的面积」 → 「平行四边形的面积」（平行四边形面积靠转化为长方形推导）
- 「分数的意义」 → 「分数加减法」
- 「小数的意义」 → 「小数加减法」
- 「等量关系」 → 「方程的意义」

### `builds_on`：B 在 A 的基础上递进，但 A 不是严格必需
B 是同一条线上的延伸或加深，学过 A 会**明显帮助**学 B，但没学过 A 的学生仍然可以（多花力气）直接学会 B。
- 「万以内数的读写」 → 「亿以内数的读写」（读写规则是延续的，但亿以内的分级读法可以独立学）
- 「用方向描述位置」 → 「用方向和距离确定位置」

### `related`：相关但没有方向性依赖
同一主题下的并列内容、可以互相印证、经常一起考，但谁也不依赖谁。
- 「2 的乘法口诀」 ↔ 「3 的乘法口诀」
- 「平行四边形的面积」 ↔ 「梯形的面积」（二者都由转化推导，彼此不依赖）

### `confusable`：易混淆
学生容易把二者混为一谈或用错，老师出题时常常把它们放在一起对比辨析。
- 「周长」 ↔ 「面积」；「去尾法」 ↔ 「进一法」；「因数」 ↔ 「倍数」

### `none`：无明显关系
不属于以上任何一种。

## 判定要点

1. 先问「不掌握 A 能否学会 B」：不能 → `prerequisite`；能，但 A 明显有帮助、且同一条线递进 → `builds_on`；否则再看 related / confusable / none。
2. **方向**：只判 A → B 这一个方向。如果你认为是 B 依赖 A 的反方向（B 是 A 的前置），请判 `none`，并在 reason 里写「反向」；`related` 与 `confusable` 无方向。
3. 「用到」不等于「前置」：B 的某道题里顺带用到了 A 的计算（如应用题里要做一次加法），但 B 这个知识点本身并不建立在 A 上 → 通常不是 prerequisite。要看 B 的**核心内容**是否依赖 A。
4. 基础性知识（如「10以内加减法」）几乎是所有后续计算的间接前置——若 B 的核心内容确实包含计算（如「两位数加两位数」），判 `prerequisite`；若 B 与计算无关（如「认识东南西北」），判 `none`。
5. 拿不准时给出最倾向的标签，用置信度如实反映。

## 输出格式

只输出 JSON：

```json
{"label": "prerequisite" | "builds_on" | "related" | "confusable" | "none", "confidence": 0.0~1.0, "reason": "不超过60字"}
```
